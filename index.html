Sabse pehle

1. Upar apna naam chuno aur PM ya RM store chuno. Naam chune bina koi entry save nahi hogi.

2. Din me ek baar Setup me jaake dekho ki Final Location, SAP aur Stock file judi hain (hari patti). Ye kaam system wala banda karta hai.

Entry tab — roz ka kaam

Upar 4 button: IN (bahar se aaya), Issue (production ko diya), Move (ek location se doosri), Return (wapas aaya).

Location, code, batch aur quantity bharo. Tool khud batata hai us location me kitna pada hai. Issue karte waqt tool sabse purana batch pehle nikalne ko kehta hai (FIFO). Save dabate hi ek confirm screen aati hai — ek nazar me sab check karke "Haan sahi hai" dabao.

Slip number zaroori hai Issue aur Return me. Bina slip save nahi hoga.

Inward tab — gadi aane par

Gate pass ki detail upar bharo, phir har code ki line "Line jodo" se add karo. Ek gadi me kai code ho to kai line. Location + batch bhar do to woh line register me apne aap IN entry bhi ban jaati hai. Aakhir me "Inward file me paste karne wala Excel" nikaalo — woh bilkul aapki purani Inward file jaisa hai, seedha copy-paste.

Dhoondho tab

Code ya location likho. Number Final Location file se aata hai, isliye jo sach me pada hai wahi dikhta hai — minus kabhi nahi. Location likho to andar ka poora maal, mix pallet bhi dikh jaata hai.

7 Din tab — aage ki planning

Agle 7 din me kya banega, uske liye carton/roll kitna chahiye aur kitna hai, kahan pada hai. Jo material kam hai woh upar laal me "purchase karna padega". Baingani (purple) wali line matlab uspe artwork ka masla hai.

Khaali tab

Jo location khaali hain unki list. Har ek pe do button — Khaali (sach me khaali hai) ya Maal hai (galat khaali dikh raha, andar maal hai). "Maal hai" dabao to code aur quantity poochta hai, woh register me chadh jaata hai aur Final file sahi ho jaati hai.

Milaan tab

Final Location file aur Stock file dono ke code ke total milaata hai. Farak dikhe to matlab kisi ek file me entry reh gayi — dono me check karo.

Hold / Reject (Smart tab)

QC ne roka hua maal yahan hold pe daalo — woh issue nahi hoga. Baad me: QC ne approve kiya (hold hat jaata hai), Vendor ko wapas (stock se minus), Scrap, ya galti se laga tha. Sab likha jaata hai kisne kiya.

Shift band karna

Shift tab me "Shift band karo" dabao. Tool pehle check karta hai — kuch SAP pending to nahi, bina slip to nahi. Sab theek ho to handover note ban ke copy ho jaata hai, group me paste kar do.

Hold tab (naya)

Saara hold pe maal ek jagah — kitne code, kahan pada hai, kis wajah se. Har hold pe 2 din me follow-up close karna zaroori (chip dabao). 2 din me na kiya to 4th din se koi nayi entry nahi hogi jab tak follow-up close na ho.

7 Din physical verify (naya)

Aaj se agle 7 din ka maal physical verify karke "7 Din" tab me date daal ke Verify OK karo. Jab tak 7 din aage tak verified nahi, nayi entry band rahegi. Aage ke din (15-25) verify karoge to aur accha.

Batch (har jagah)

Dhoondho, issue/in/return/move — sab jagah batch dikhta hai. Issue karte waqt neeche batch ki list aa jaati hai (purana pehla — FIFO), Dhoondho jaana nahi padta. Bulk IN me total qty daalo to khaali jagah khud baant ke deta hai.

Zaroori baatein

• Tool ko hamesha computer (Chrome/Edge) me kholo. Mobile ke Downloads se khologe to data save nahi hoga.

• Hafte me ek baar Setup se Backup download karo.

• Har entry pe naam chipakta hai — kaam sahi karo, galti ka pata chal jaata hai.
